# Platium — Advanced OSINT Framework

**Platium** is a professional open-source OSINT framework designed for security researchers, journalists, and digital investigators. It gathers and analyzes publicly available information from 60+ sources with speed and accuracy.

---

## 🚀 Features

- 🔍 **Username Search** — 60+ platforms (GitHub, Twitter, Instagram, VK, Reddit, etc.)
- 📧 **Email Scanner** — Data breach detection via HIBP + public databases
- 📱 **Phone Analysis** — Country, carrier, timezone, operator info
- 🌍 **IP Scanner** — Geolocation, ISP, organization, WHOIS data (Shodan)
- 🖼️ **EXIF Extraction** — Metadata from images (GPS, camera model, date)
- 📊 **Social Analyzer** — Search profiles on Instagram, Twitter, Facebook
- 🌐 **Darknet Scanner** — Search through .onion sites via Ahmia
- 🔗 **Graph Builder** — Build connection graphs based on email
- 🛡️ **Threat Intelligence** — Check IPs/emails via VirusTotal and Shodan
- 📄 **Report Generator** — Save results in TXT, JSON, and HTML
- 🎨 **Interactive UI** — Cyber-style menu with animations
